**SpotiSearch**

This is a personal project that will search 4 different sources:
Wikipedia, MusicBrainz, Album Of The Year, Itunes
for information on the latest albums of the top x artists. The app will then display, in chronological order, the upcoming releases.

Written in TS/JS 
Database is PostGres 


All sources except AOTY have api's to use, AOTY will be scraped. At the end of each day, at 12am, the list will be updated to catch any midweek announcements.
